## 二、 核心产品与交互设计灵感（自由探索，仅供启发）

我们不对具体页面进行死板规范，**你可以天马行空地发挥你的交互设计功底**。以下列举核心产品维度的参考构想：

### 1. 优先聚焦手机竖屏体验（Mobile-First Portrait）
* 核心操作区域贴合大拇指热区，交互手感丝滑，输入框键盘弹出与消息流滚动平滑防抖。

### 2. 告别冷冰冰表单，采用“对话式渐进建档”（Chat-First Onboarding）
* 用户初次进入产品，不要抛出一堆繁琐生硬的日期时间输入框！
* **从一个亲切温暖的聊天框直接开始**：AI 像一位熟络睿智的老友，在自然对话中顺势了解用户的昵称、生辰时间或当前心事，温和完成背景采集，建立用户画像。

### 3. 参考主流优秀聊天体验（DeepSeek / 微信 / Claude）
* **视觉层次**：用户消息居右自如呈现，AI 消息居左，排版留白舒适，行高适宜。
* **深度思考折叠**：若涉及复杂玄学推演或思考过程，设计优雅的折叠面板（如“已推演八字格局 ▼”），展开后可见清晰逻辑，默认保持界面干净。
* **消息级交互**：支持复制、重新生成、引用、导出分享长图等。
* **动态标题与分类管理**：系统根据对话进展，自动为会话生成洗练标题并智能分类归档。

### 4. 算命专业性与工具集成（多维交互 / 独立 Tab 联动）
* 既有像呼吸一样自然的情感陪伴，也有严谨的命理专业能力。
* 可以将八字四柱、紫微斗数、周易六爻铜钱摇卦、韦特塔罗牌阵等设计为 LLM 可调用的富交互卡片（Widget），或者通过多 Tab 联动（如聊天 Tab 与排盘测算 Tab），且推演记录妥善持久化保存。

## 三、 商业化变现与“情价比”机制（商业级产品要求）

我们要做的是一个可变现的真实产品，请设计合理的商业与用户留存链路：

1. **用户体系与本地持久化**：

2. **算力与情绪的“生活拟物化”捐赠/打赏机制**：
   * 形式可灵活探索（如会员订阅，或更具亲和力的“自愿打赏/功德捐助”）。
   * **特色设计——Token 的生活化度量**：在合适位置优雅展示今日或累计消耗的算力 Token，并通过 LLM 根据用户画像进行动态生活化类比（如：*“今日消耗 12,800 算力 ≈ 1.2 杯赛博拿铁 / 2 炷静心清香 / 3 个热腾腾的大馒头”*）。
   * 提供“请喝一杯咖啡/随喜功德”的轻盈弹出层，支持展示收款二维码或赞赏通道。
3. **“既赚聊天的钱，也赚算命的钱”**：
