## 一、 技术栈与创作自由度（Tech Stack Freedom）

1. **完全自由的技术栈选择**：
   * 本项目**不对技术框架做任何硬性限制**（无论你选择 Next.js、React、Vue 3、Svelte，还是配合 Tailwind CSS、Framer Motion、Three.js、ECharts、Canvas 等现代工具）。
   * 请根据你最擅长、最能兼顾**丝滑动画渲染性能**、**丰富音画微交互**与**工程交付速度**的技术组合自由选型与发挥。
2. **鼓励主动联网检索与学习**：
   * 强烈鼓励你在开发过程中主动联网检索与调研：包括但不限于 Awwwards 获奖级动效设计、Co-Star 极简冷黑版式设计、Sanctuary 宇宙渐变质感、transitions.dev 现代页面过渡、Web Audio API 真实物理音效合成、以及最新的 Canvas/WebGL 粒子流特效。
   * 吸收最前沿的视觉传达和触觉反馈实践，将其转化为产品中震撼人心的体验。

## 二、 核心设计语言与视听美学（Visual & Audio Aesthetics）

1. **视觉风格：赛博新中式与新神秘主义（Neo-Cyber Mysticism）**
   * **主色调**：
     - 极夜太虚黑 (`#08090D`) 作为全局底色，搭配沉香暗褐 (`#12151D`) 高斯模糊卡片（`backdrop-blur-xl`）。
     - 纯阳真金 (`#D4AF37`) 与琉璃暖金 (`#F5D77F`) 作为核心点睛高光、卦象线条与高能量K线。
     - 灵符朱砂红 (`#E63946`) 用于印章、凶煞化解节点、警示爻辞与下跌K线。
     - 碧落苍玉绿 (`#2A9D8F`) 与太阴幽蓝 (`#3A86FF`) 用于生发五行、星盘轨迹与上涨K线。
   * **排版韵律**：
     - 标题与典籍引文使用高贵典雅的传统宋体/楷体风骨字体族（`Noto Serif SC`, `Source Han Serif SC`, `Songti SC`），字距适度放宽。
     - 数据与量化指标采用等宽科技字体（`JetBrains Mono`, `Space Grotesk`）。
   * **质感与光影**：微发光描边（`border: 1px solid rgba(212, 175, 55, 0.18)`）、动态星轨粒子、金石红白方印徽章。

2. **音效与触觉体系（Web Audio API / Haptic）**：
   * 建议采用轻量 Web Audio API 动态合成或内置无版权精美音效：
     - 摇铜钱清脆碰撞声、432Hz 颂钵长波泛音、寺庙古钟微鸣、空灵赛博木鱼敲击声。

## 三、 必须完整实现的四大功能殿堂与推演模块

项目必须包含清晰的模块导航与流畅的转场，杜绝一切未实现页面和空链接：

### 1. 【太虚灵台】（Portal & Daily Sanctuary）
* **每日天机日历**：展示今日干支黄历、今日宜忌（如“宜：凝神、重构知识库；忌：盲动冒险”）、每日灵犀金句。
* **心念调频仪式**：4-7-8 呼吸光环（吸气扩展、屏息蓄能、呼气收缩），提供长按 3 秒聚焦意念转场。
* **赛博木鱼清心台**：中央高精度质感黑檀木鱼，点击发出空灵木鱼音效，屏幕向上漂浮动态微光字符（`功德 +1`、`焦虑 -1`、`心定神宁 +1`），记录功德计数。

### 2. 【天机推演殿】（The Divination Sanctum - 核心推演引擎）
用户可自由切换五大推演子模块：
* **模块 A：八字四柱与“人生量化K线图”**
  - 公历/农历智能切换选择器，支持时辰精准选择与容错。
  - **真太阳时罗盘校准仪式**：输入地点后，唤起二十四山罗盘旋转校准动画（显示经纬度与时差补偿）。
  - **八字四柱与五行能量雷达图**：展示年月日本命八字干支、十神标签、五行金木水火土能量多边形雷达。
  - **1~100岁交互式人生K线图**：
    * 采用 ECharts 或 Canvas 自研实现完整的金融级 K 线图（横轴：年龄与年份，纵轴：0~100 运势能量值）。
    * 鼠标悬浮 / 移动端点按弹出该年份的 OHLC 四值、高光/阻力事件标签（如“32岁 官印相生 主升浪”）与流年批语。
* **模块 B：周易六爻三枚铜钱摇卦台**
  - 提供清代乾隆通宝铜钱 3D/物理翻滚动画，支持点击摇动或移动端摇晃手机。
  - 掷六次铜钱，每次根据正反面判定字背，自下而上逐爻绘制六爻爻画（老阳、老阴、少阳、少阴）。
  - 完整推导本卦、互卦与变卦，展示白话卦辞与现代心理学破局指南。
* **模块 C：塔罗星穹悬浮牌阵**
  - 支持【单牌指引】、【圣三角过去-现在-未来】、【关系双轨】等经典牌阵。
  - 78 张精美卡牌以半圆弧流光扇面悬浮展开，支持指针滑过的高低起伏回弹。
  - 抽取卡牌进入仪式位，支持 3D 翻牌动效揭晓大阿卡纳正面/逆位与神圣批语。
* **模块 D：赛博灵签筒与掷圣杯**
  - 摇动竹签筒，伴随撞击碰撞声脱落灵签（如“第十九签 上吉”）。
  - 掷出两枚半月形红木圣杯，精确计算【圣杯（一平一凸）】、【笑杯】与【哭杯】逻辑。

### 3. 【宿命酒馆】（The Oracle Tavern - 多智能体沉浸对话）
用户进入充满氛围感的灵霄客栈，与五位特色大师进行深度多轮对话：
* **五位预置大师席位**（支持抽屉式丝滑切换）：
  1. **玄玑道长**：终南山隐修老道，语气古雅沧桑，擅长八字五行与阴阳调和。
  2. **赛博萨满 ZERO**：量子数据流观察者，冷峻极客风格，擅长以系统工程与概率波解读命运。
  3. **瑟琳娜 (Selena)**：深夜塔罗执牌人，温柔疗愈，擅长亲密关系剖析与荣格潜意识引导。
  4. **鬼谷策谋士**：战国纵横权谋家，辞锋如刀，专注于职场博弈、利益格局与破局实操。
  5. **临风先生**：民国儒雅文人，温润如风，长于安抚中年内耗与重建精神信仰。
* **双轨叙事渲染机制（Dual-Track Prose）**：
  - 大师输出自动区分为：`*舞台动作与环境微描写*`（古金斜体或淡字号）与 `"大师台词与洞见"`（正文高亮）。
* **接口与自洽引擎**：
  - 界面提供 API 设置弹窗（支持填入 OpenAI/Gemini/DeepSeek 兼容端点与 Key 实现真实流式打字输出）。
  - **必须内置完备的离线 Mock 对话决策树**：即使未配置外部 Key，也能针对事业、情感、迷茫等问题给出丰富自洽的多轮高质量双轨回复！

### 4. 【命书典藏阁与黄金分享工坊】（Archive & Golden Poster）
* **个人命运档案**：自动保存用户的测算记录与历史卦象。
* **高光长图海报导出**：
  - 一键渲染尊贵黑金长图卡片（包含个人四柱八字、五行雷达缩略图、人生K线主升浪截图、大师批语、红色朱砂方印）。
  - 支持 Canvas / HTML2Canvas 一键下载为高质量 PNG 图片，或一键复制金句，满足朋友圈与社交分享传播。

## 四、 核心交互状态流转与“有意义的摩擦感”规范

推演过程必须杜绝“点击即瞬间弹窗”的廉价感，严格实现以下五步沉浸心流状态机：
1. **IDLE（意念启始）** $\to$ 输入生辰或意念叩问。
2. **CALIBRATING（天时校准）** $\to$ 真太阳时罗盘旋转与呼吸聚焦（1.5s）。
3. **INTERACTING（物理仪式）** $\to$ 摇卦掷铜钱 / 悬浮选卡牌 / 摇动签筒（用户参与）。
4. **COMPUTING（天机演算）** $\to$ 维持 3~4 秒神圣推演动效（太极阴阳转动、古籍翻页微光、“正在遍历万年历与格局拓扑...”动态提示）。
5. **REVEALED（命书显化）** $\to$ 舒展展现数据与批语，支持多维度下钻与海报导出。
