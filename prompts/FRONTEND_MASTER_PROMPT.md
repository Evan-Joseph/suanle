  * 上方为易经六十四卦之**【坤卦】（☷ 六断爻）**，象征大地之宽厚、包容、柔顺与承载；同时这六道横杠巧妙化作一双微眯的**笑眼**。
  * 下方为一道温暖上扬的**微笑曲线**。
  * 组合在一起是一张富有东方哲思与当代 Emoji 幽默感的“松弛笑脸”。
* **产品基调**：
  * **拒绝中二与故弄玄虚**：不要搞浮夸修仙、神魔宗门或恐怖宿命论。

## 二、 你的自由度：完全不受限的创作空间

1. **技术栈完全自由**：
   * 你可以使用你最擅长、最能打磨出极佳交互体验的任何技术栈（无论是 Next.js、React、Vue 3、Svelte，还是 Tailwind CSS、Framer Motion、Three.js、ECharts、Canvas、Web Audio API 等）。
2. **交互形式与内容设计完全自由**：
   * 你可以自由构思从“算”到“算了”的整个交互链路！
   * 例如（仅作灵感启发，绝非强制）：
     - 你可以做一个“把心事写在纸条上揉成团扔进垃圾桶”的物理动效；
     - 也可以做一个“一键算了”的解压释怀按钮；
     - 可以让用户摇铜钱、抽塔罗、测八字或看人生波动，但最终的 AI 结论永远是一个通透、温柔、令人会心一笑的“算了建议”；
     - 甚至可以设计呼吸降压、电子木鱼听个响、幽默运势日报、或者生成一张极简漂亮的“算了卡片”分享到朋友圈。
   * **只要符合“算一算，然后，算了”的品牌灵魂，具体交互逻辑任你天马行空地发挥！**
3. **鼓励主动联网检索与学习**：
   * 强烈鼓励你联网检索参考前沿产品（如 *The Pattern*、*Co-Star*、*Sanctuary*、*潮汐*、*Calm* 等）的排版设计与微交互，汲取最佳实践。

## 三、 设计与视觉建议（Visual Guidance）

1. **视觉美学：现代极简、柔和、降温感**：
   * 推荐使用干净、低饱和度的自然色调（如纸白、曜岩灰、陶土棕、晨雾蓝等），避免刺激人眼与神经系统的高饱和度荧光色。
   * 善用呼吸感留白与精致的版式编排，让界面宛如一本捧在手心里的生活散文集。
2. **动态与音画体验**：
   * 动效应当是轻柔、舒缓、具有物理回弹感的。
   * 如有音效，推荐轻脆微小的物理白噪音（如落纸声、风铃泛音、轻击木鱼声），带来真实的触觉抚慰。

## 四、 交付与质量要求（Production-Ready Checklist）

1. **体验完整性**：
   * 所有按钮、开关、卡片都必须有真实的交互反馈，严禁出现无效死链或未完成的占位。

   * 同时建议预留通用的大模型 API 配置入口（如兼容 OpenAI/Gemini 端点），方便随时接入真实流式 AI 对话。
3. **响应式适配**：
   * 无论在电脑宽屏还是手机竖屏上，都应展现出舒适、自如的排版体验。
