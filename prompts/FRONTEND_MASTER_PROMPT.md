## 三、 你的自由度与核心设计启发（非死板限定，供你自由发挥）

我们**不对你的页面层级、路由或具体功能清单做任何死板限制，甚至交互内容都可以让你自由设计！**
以下提炼自团队的核心设计点子，供你参考并融入你的创作中：

### 1. 极其重视手机竖屏端体验（Mobile-First by Default）
* 绝大多数用户是在深夜被窝里、地铁通勤或独自散步时单手使用本产品。
* 请优先保证移动端体验：大拇指热区舒适、视口滚动阻尼自然、软键盘弹起时视口防遮挡防跳动、触觉微震动反馈（Haptic API）。

### 2. 从亲切温和的“聊天框”切入（Conversational Entry）
* **拒绝冷冰冰的机械大表单**：初次见面不要甩出一个复杂的生日、时辰、地点输入表单，用户会觉得繁琐而产生心理抗拒。
* **接入大模型的对话式信息采集**：像一位亲切的老朋友初次打招呼一样，在聊天流中通过 1~2 轮温和的日常问答（如“今天遇到什么烦心事了？”或附带轻量标签胶囊 Pills 供点击），不知不觉间自然获取用户的背景或困惑，并始终允许用户跳过。
* **界面风格参考优秀移动端**：
  - 学习 **DeepSeek**、**ChatGPT** 与 **微信** 的聊天美学：极简、呼吸感强、气泡间距得当、输入框吸底优雅、长文本横向滚动代码/卡片不撑破布局。
  - 支持 **思考过程（Thinking Process）的可视化折叠卡片**：在输出深度解读前，可以折叠展示 AI 正在梳理卦象与心绪的微光脉络。

### 3. “有人味，看不出是 AI”的酒馆与解读提示词设计
* 算命与解惑的核心在于**“去机器味，注入灵魂”**：
  - 彻底摒弃“作为一个人工智能语言模型……”、“首先、其次、综上所述……”等机械套话与说教感（爹味）。
  - 借鉴酒馆（SillyTavern）的最佳实践：语言要有呼吸感、生活化语气词、短句、轻度叹气或幽默感，适度带有自然的场景微动作（如：`*喝了口温水，把眼前的牌推开*`）。
  - 既有对易经、星盘、八字或生活常理的深刻洞察，又能在关键时刻一语点醒梦中人，传递出“算了”的超脱与自愈力量。

* **变现模式设计（订阅 / 单次测算 / 自愿功德打赏）**：

### 6. 专业玄学工具化集成（Tools & Dedicated Tabs）
* 专业性不能丢：八字排盘、周易六爻摇卦、塔罗抽牌等不仅能在聊天中作为 LLM 内部工具调用呈现，也可以设计为独立的工具 Tab（如【今日一卦】、【塔罗牌阵】、【人生波动图】）。
* **记录妥善管理**：日常对话随意发生，但重大的“年算”或“本命盘”应支持归档在用户的专属档案中，避免被繁杂的闲聊记录淹没。

## 四、 规避 AI 通病与工业级排版铁律（Anti-Flaws & Quality Checklist）

为确保最终交付的界面达到 Apple / Linear 级别的工业精度，请严格遵守以下防错规范：

1. **排版防塌陷铁律**：
   * 所有 Flex/Grid 容器中包含文本的子项必须显式加上 `min-w-0`，避免长标题或无空格字符撑破屏幕容器。
   * 移动端输入框必须针对 iOS Safari 软键盘弹出做针对性防抖处理（`visualViewport` 适配）。
2. **丝滑打字机 Markdown 渲染**：
   * 接入流式（Streaming）输出时，Markdown 解析必须平稳，不得出现因为代码块、表格未闭合而导致的屏幕疯狂跳动或闪烁。
3. **对话与标题智能生命周期**：
   * 必须实现像 ChatGPT / Claude 一样的会话管理：
     - 新会话开始时不急于定标题；
     - 在第 2~3 轮对话时，调用 LLM 后台异步自动总结出简短传神的标题（如“纠结离职的那个深夜”、“关于今年桃花的困惑”），并在侧边栏或历史列表中自动更新归类。
4. **四态齐全（The 4 Essential States）**：
   * 任何模块都必须包含：正常态、加载态（Skeleton 骨架屏）、空状态（Empty State 带有松弛幽默的插画或文案提示）、错误容错态（网络中断时优雅重试，而非生硬报错）。
5. **离线自洽保底（Offline Fallback）**：
   * 即使在完全断网或未配置 API Key 的极端情况下，内置的 Mock 决策树与本地推演算法也能让用户顺畅跑通一个包含“算卦 $\to$ 深度解说 $\to$ 建议算了”的完整演示链路。
