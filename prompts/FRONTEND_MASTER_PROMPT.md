## 二、 时代心理共识与用户心智（Societal Context for 2026+）

请在设计整个产品的语气、视觉节律与交互逻辑时，深刻共情当下社会的普遍心境：
1. **告别宏大与狂躁，渴望“微小确定性”**：
   * 面对外部环境的波动与生活节奏的高压，年轻人普遍身心疲惫。他们需要的不是故弄玄虚的恐吓式预言或宏大教条，而是在具体、微小的当下获得精神喘息。

## 三、 你的完全自由度：交互与架构无边界探索

**我们不对任何具体页面划分、功能范围或交互链路设限，请发挥你的全部功底自主设计与实现**。以下方向与构想仅供参考与灵感启发：

### 1. 优先聚焦手机竖屏体验（Mobile-First Portrait）
* 核心操作区域贴合大拇指热区，交互手感丝滑顺畅。
* 键盘唤起时视口挤压自如，消息流与内容区域平滑防抖，滚动反馈自然。

### 2. 聊天优先与对话式渐进建档（Chat-First Onboarding）
* 告别冰冷、繁琐、像查户口一样的出生信息表单。
* 用户初次进入，不妨从一个温和亲切的聊天界面开始，由 AI 在自然对话中像一位熟络老友般顺势了解用户的心事、称呼或生辰线索，在无形中完成用户画像沉淀。

### 3. 参考前沿顶级移动聊天交互
* 借鉴 DeepSeek 手机版、微信、Claude 等一流移动交互范式：
  * **思考折叠胶囊**：涉及复杂推演或分析时，设计优雅的折叠条（如展开/收起推演过程），保持对话主干干净从容。
  * **流式打字与消息操作**：平滑细腻的流式响应光标，支持便捷的复制、重新生成、引用或长图分享。
  * **会话自管理**：系统根据对话进展与意图，自动生成洗练标题，并随对话深入自动归纳、分类与动态更新。

### 4. 专业术语的生活化重构与多元工具联动
* 兼具东方术数（八字、紫微、周易六爻）与西方神秘学（占星、塔罗）的专业内核，但将其表达转化为温暖易懂的人文语言。
* 可以将算命方法设计为 LLM 自主调用的富交互卡片（Widget），也可以设计独立的探索 Tab 供用户自主演练（如摇铜钱、选塔罗），推演历史（如年度大盘）妥善管理与持久化保存。

## 四、 商业化变现与“长效情价比”设计（真实商业产品）

这是一个旨在实现健康商业循环的产品，“既要赚聊天的钱，也要赚算命的钱”，请设计自然、无痛的价值回馈机制：

1. **用户体系与本地持久化**：
   * 采用浏览器本地存储（IndexedDB / LocalStorage）或账号机制，确保用户的会话记录、命盘档案、用户画像与偏好长期安全留存。
2. **算力与情绪的“生活拟物化”捐赠 / 付费机制**：
   * 探索订阅制、按次解锁或更具亲和力的“自愿打赏 / 随喜功德”：
   * **巧思——Token 消耗的生活化度量**：在合适位置优雅呈现用户本次或累计消耗的算力，并由 LLM 根据用户画像动态选择贴切的日常事物进行幽默类比（例如：*“本次推演消耗 16,800 算力 ≈ 1.5 杯热拿铁 / 2 炷清心香 / 3 个刚出锅的肉包子 / 0.5 棵虚拟绿植”*），并支持弹出轻盈的打赏收款码或赞赏通道。
3. **文案高级感规范**：
   * **界面文案严禁自嗨式技术说明**：绝对不要在面向用户的文案中出现“我们设计了订阅系统”、“本产品离线也可访问”、“底层已接入大模型”等生硬多余的程序员黑话。一切文案均以自然、真实、有温度的用户视角呈现。
