## 三、 核心产品与交互体验规范（重新对齐）

### 1. 优先聚焦手机竖屏体验（Mobile-First Portrait）
* 核心操作贴合移动端大拇指热区，键盘弹起与消息流自如滑动，避免一切横向溢出。

### 2. 聊天优先与对话式渐进建档（Chat-First Onboarding）
* 告别冰冷的开门表单，从亲切温馨的对话框起步，通过自然对话顺势了解用户的心事与生辰信息，温和建立画像。

### 3. 参考主流优秀移动体验（DeepSeek / 微信）
* **深度推演折叠**：涉及命理格局或复杂推演时，设计类似 DeepSeek 的“思考过程”折叠胶囊，展开可见推演细节，默认保持对话流整洁。
* **消息流与操作**：支持便捷的复制、重新生成、会话标题自动提炼与动态分类。

### 4. 商业闭环与“生活拟物化”算力打赏机制
* 这是一个可变现的真实产品，包含用户状态与本地持久化（IndexedDB / LocalStorage / 认证）。
* **特色 Token 生活化度量**：在合适位置将消耗的算力 Token 类比为具象生活物品（如：*“本次消耗 16,800 算力 ≈ 1.5 杯热拿铁 / 2 炷清香 / 3 个热腾腾的包子”*），由 LLM 根据用户画像动态选择类比对象，并支持弹出收款码/赞赏弹窗。
* **文案规范**：**严禁在面向用户的界面上写自嗨式技术说明**（绝不能出现“我们设计了订阅”、“离线也可访问”等程序员语言），保持高级自然的人文表达。

### 5. 专业性与工具联动
* 涵盖八字、周易六爻（铜钱摇卦）、韦特塔罗等体系，可作为聊天中 LLM 调用的富交互卡片（Widget），也可与独立的探索模块联动，历史推演妥善归档。
