## 二、 核心任务：六合一融合与重构原则（取其精华，去其糟粕）

请首先完整阅读并审计上述 6 套源码，梳理各版本的最佳模块，进行有机融合：

### 1. 取其精华（必须继承并升华的亮点）
* **移动端聊天优先体验（借鉴 2 / 4 / 6）**：
  * 首屏温和自然的对话流引导（Chat-First Onboarding），告别机械生硬的生辰表单，在日常闲聊中自然沉淀用户画像；
  * 参考 DeepSeek 与微信的移动端交互：优雅的思考折叠胶囊（Thinking Capsule）、流畅的流式输出、会话自动命名与动态分类更新。
* **专业玄学工具矩阵与多维联动（借鉴 1 / 3 / 6）**：
  * 八字排盘（精确到真太阳时与中华万年历 Lunar 节气支持）、周易六爻三枚铜钱物理摇卦、韦特塔罗牌阵、人生K线能量图谱；
  * 工具既能作为独立功能板块查验，也能作为 AI 在对话中自主调用的富交互卡片（Widget），并妥善持久化保存推演记录。
* **独家灵魂——“算了”释怀仪轨（借鉴 3 / 6）**：
  * 深度提炼 `LetGoView` 核心理念：将现实烦恼具象化（如写在虚拟便签纸上），通过物理交互（揉成纸团丢入纸篓、或者灰烬消散动效），带来真实的心理卸压与情绪降温。
* **商业闭环与生活化 Token 赞赏（借鉴 4 / 5 / 6）**：
  * `TipSheet` 与 `LampSheet`：由 LLM 动态将消耗的算力 Token 类比为具象生活事物（如：*“本次推演消耗 16,800 Token ≈ 1.5 杯拿铁 / 2 炷清香 / 3 个热包子”*），弹出轻盈的打赏收款码或自愿赞赏通道，兼顾聊天与算命的商业变现。

### 2. 去其糟粕（必须全面排查并修复的缺陷）
* **排版与居中问题**：彻底解决手机小屏下的水平溢出滚动、元素未垂直居中、断行突兀、底部安全区（Safe Area Inset）遮挡输入框等基础排版 Bug。
* **文案与元素重复**：
  * 清理各组件间重复出现的 Slogan、多重嵌套的标题栏或冲突的免责声明；
  * **杜绝程序员自嗨式技术文案**：界面严禁出现“我们设计了订阅”、“支持离线运行”、“使用了Gemini大模型”等生硬技术描述，所有文案保持温润、克制、接地气的人性化口吻。
* **渲染与交互瑕疵**：
  * 杜绝富文本流式渲染时的裸露 Markdown 标记（如未闭合的 `###` 或代码块跳动）；
  * 消除抽屉弹窗动画卡顿、键盘弹出时的视口抖动、以及死循环加载态。
