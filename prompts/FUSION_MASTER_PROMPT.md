## 四、 商业级产品核心机制（重述与坚决落实）

最终融合版本必须是一个真正能跑通商业变现的闭环产品，请将以下核心体验贯彻到底：

### 1. 品牌灵魂与视觉资产
* **产品名称**：算了 · Suanle
* **Slogan**：算一算，然后，算了。
* **Logo 图腾**：易经坤卦六断爻形成的眯眼笑脸 + 上扬微笑曲线（位于仓库 `assets/logo.jpg`、`logo.svg`）。
* **视觉气质**：现代极简、柔和微温、克制留白，杜绝浮夸躁动。

### 2. 手机竖屏优先与对话式渐进建档（Chat-First Onboarding）
* 优先保障移动端单手操作流程度。
* 用户初次进入，直接呈现温暖的会话窗口，AI 像一位懂分寸的老友般自然寒暄，在对话流中温柔采集用户昵称、生辰时间或当前心事，无感建立用户偏好。

### 3. 前沿移动聊天范式（参考 DeepSeek / 微信）
* **深度思考折叠条**：将大模型复杂的格局推演、卦辞检索收纳于优雅的胶囊条中，支持随时展开查看，保持对话主干干净。
* **严谨的富文本解析**：流式输出平滑防抖，**严禁裸露未经转义的 Markdown 语法标识或代码块标记**。
* **会话自管理**：系统根据对话进展与意图，自动生成洗练标题，并随对话深入自动更新会话命名与分类。

### 4. 商业化收单与“生活拟物化”算力打赏
* **既要赚聊天的钱，也要赚算命的钱**；
* **用户与数据持久化**：使用浏览器本地存储（IndexedDB / LocalStorage）或账号机制，确保会话、命盘档案、用户画像长期安全保存；
* **Token 的生活化度量与赞赏弹窗**：在适当时机优雅展示消耗的算力，并通过大模型结合用户画像进行生活化生动类比（如：*“本次推演消耗 16,800 算力 ≈ 1.5 杯热拿铁 / 2 炷清心香 / 3 个刚出锅的肉包子”*），并弹出赞赏打赏收款码。
* **文案禁忌**：**界面文案严禁自嗨式技术说明**，绝不在界面中出现“我们设计了订阅”、“支持离线访问”等生硬的技术自述。
