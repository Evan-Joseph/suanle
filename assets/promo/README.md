## 一、 品牌核心哲学与叙事基调 (Brand Philosophy)

* **产品定位**：一个懂八字、紫微、六爻、塔罗，更懂人心的老朋友。
* **核心口号（Slogan）**：“算一算，然后，算了。”
* **精神内核**：
  * 人总是在执念与迷茫中想要算尽天机，但推演的本质不是走向宿命论的认命，而是为了“在看清局限后，体面而平静地放下执念”。
  * 区别于传统玄学工具的焦虑贩卖或神秘主义包装，《算了》是一场心理疗愈与东方豁达哲学的融合——递上一杯刚泡好的热茶，陪你把心里的乱麻理一理，然后，轻轻松松地“算了”。
* **视觉美学**：
  * **宋代极简美学**：宣纸白、徽墨黑、朱砂印章红、松石绿、秋香金；
  * **呼吸感留白**：拒绝科技界冰冷的赛博朋克或刺眼霓虹，采用温润的纸本墨韵、柔和的光影渐变与细腻的微质感；
  * **核心仪式感**：手写放不下的心事 → 褶皱揉成纸团 → 抛物线投掷进纸篓 → 沉静的颂钵/铜磬回响 → “今天又算了 1 件”。

## 四、 推荐音效设计与配乐氛围 (Sound Design & Foley)

1. **环境底噪（Ambient Bed）**：
   - 细微的窗外细雨、远山晨风、炭火煮茶的微沸水声，营造极度静谧、让人卸下防御的心流氛围。
2. **拟音细节（Foley Effects）**：
   - **茶盏轻碰**：温润的瓷器触碰声（Opening）；
   - **铜钱摇卦**：清脆的三枚青铜钱币碰撞与在木桌上的旋转停顿；
   - **纸张揉皱**：真实纤维纸张由平展迅速被揉捏聚拢的清脆纸褶声（`crumple.mp3`）；
   - **抛掷与入篓**：轻巧的空气破风声与纸团落入竹纸篓的钝响（`thud.mp3`）；
   - **落定余韵**：清澈悠远的喜马拉雅颂钵（Singing Bowl）或古寺铜磬鸣响，尾音逐渐衰减飘散；
   - **印章钤盖**：重重按在宣纸上的沉闷微震感。
3. **配乐旋律（BGM）**：
   - 新世纪东方古典（New Age / Neo-Classical Ambient），古琴、尺八或低音大提琴单音穿透，极少密集节奏，以悠长气口带出旷达感。
