## 1. 东方术数符号体系与算法映射

### 1.1 子平八字（Four Pillars of Destiny）推演体系
八字模型以中国农历与真太阳时节气为锚点，将时间离散化为四对干支组合（共八字）：

```
[年柱 (天干+地支)] [月柱 (天干+地支)] [日柱 (天干+地支)] [时柱 (天干+地支)]
       │                  │                  │                  │
    祖上/根基          父母/成长          自身/日元(核心)      晚运/产出
```

#### 核心推演算子：
1. **日元主宰（Day Master）**：日柱天干代表自我的本质（甲乙木、丙丁火、戊己土、庚辛金、壬癸水）。
2. **五行衰旺与气数评估**：
   * 考量日元生于何月（得时/不得时）、地支通根（得地/不得地）、同类相生扶（得势/不得势）。
   * 输出五行相对权重值：$W_{\text{wood}}, W_{\text{fire}}, W_{\text{earth}}, W_{\text{metal}}, W_{\text{water}}$，且 $\sum W_i = 100\%$。
3. **十神关系映射（The Ten Gods）**：
   * 同我者：比肩（竞争合作）、劫财（破耗豪爽）
   * 我生者：食神（温和才艺）、伤官（锋芒反叛）
   * 我克者：正财（稳健财富）、偏财（流动投机）
   * 克我者：正官（制度名誉）、七杀（魄力风险）
   * 生我者：正印（庇护学问）、偏印/枭神（独创直觉）
4. **大运流年能量叠加**：
   * 每十年一步大运（排运起运点），每年一个流年干支。
   * 流年干支与原局产生刑、冲、克、害、合、化反应，形成年度综合顺逆势评分。

### 1.3 周易六爻与梅花易数（I Ching Hexagram Dynamics）
周易起卦是离散动态演化算法（Markov-like Transition）：
1. **基础起卦（摇卦法 / 铜钱法）**：
   * 掷三枚铜钱共六次，从初爻自下而上排列。
   * $3 \times \text{背} = 9$（老阳，变爻 $\to$ 阴）
   * $2 \times \text{背} + 1 \times \text{字} = 8$（少阴，静爻）
   * $1 \times \text{背} + 2 \times \text{字} = 7$（少阳，静爻）
   * $3 \times \text{字} = 6$（老阴，变爻 $\to$ 阳）
2. **三元卦象态**：
   * **本卦（Original Hexagram）**：当前现状与事物基本盘（如：地火明夷卦，象征光明受损，需低调韬光养晦）。
   * **互卦（Nuclear Hexagram）**：事物内在蕴藏的暗流与中间演化过程。
   * **变卦（Resulting Hexagram）**：随着动爻演化后的终局走势与启示。

## 2. 西方神秘学符号体系

### 2.1 现代心理学占星（Psychological Astrology）
1. **三位一体核心**：
   * **太阳星座**：显意识、核心驱动力、想要成为的样子。
   * **月亮星座**：潜意识、情绪安全感、本能的情感反应。
   * **上升星座**：社会人格面具、面对外界的第一反应与处世姿态。
2. **行星与能量象征**：
   * 个人行星：水星（思维沟通）、金星（美与爱感）、火星（行动欲力）。
   * 社会行星：木星（扩张机遇）、土星（界限磨砺）。
   * 世代行星：天王（颠覆创新）、海王（梦幻灵性）、冥王（蜕变重生）。
3. **几何相位（Aspects）动力学**：
   * 调和相位：拱（$120^\circ$ 自然流通）、六合（$60^\circ$ 协助激活）。
   * 挑战相位：刑（$90^\circ$ 内在冲突与突破推力）、冲（$180^\circ$ 对立投射与整合课题）。

### 2.2 韦特塔罗牌（Waite Tarot）意象系统
全套 78 张牌：
1. **22 张大阿卡纳（Major Arcana）**：人生的英雄之旅（The Hero's Journey），代表精神觉醒与生命重大课题。
2. **56 张小阿卡纳（Minor Arcana）**：四大元素对应的世俗生活细节：
   * 权杖（Wands，火）：意志、创造、野心、动力。
   * 圣杯（Cups，水）：情感、关系、直觉、潜意识。
   * 宝剑（Swords，风）：理智、争论、清晰、思维之痛。
   * 星币（Pentacles，土）：财富、物质、健康、长期沉淀。
3. **经典牌阵规范**：
   * **单牌指引（Daily Spark）**：今日当下能量指引。
   * **圣三角牌阵（Holy Triangle）**：过去的因、现在的实、未来的势。
   * **关系双轨牌阵（Two-Paths）**：双方心理、互动阻碍、发展走向。
   * **凯尔特十字（Celtic Cross）**：全景深度扫描（核心现状、交叉挑战、潜意识根基、过往影响、外部环境、自我希望与终局）。

## 3. “人生量化K线图”算法推演模型（OHLC Model）

将八字大运流年与紫微星力结合，抽象为类似金融时序数据的运势 OHLC（Open, High, Low, Close）序列：

### 3.1 坐标系与量化公式
* **横轴（$X$ 轴）**：年龄（$1 \sim 100$ 岁）与对应公历年份。
* **纵轴（$Y$ 轴）**：运势活力指数（$0 \sim 100$ 分）。
  * $50$ 分：平衡荣枯线。
  * $>65$ 分：多头吉势（得天时地利，适合顺风开拓）。
  * $<40$ 分：空头磨砺（逢冲克破害，宜积蓄能量、守正蓄力）。

### 3.2 K线四值物理语义映射
$$\text{Score}(t) = \text{Base} + f_{\text{大运}}(t) + g_{\text{流年}}(t) + \epsilon$$
1. **Open（岁首开盘）**：立春交节气之时的综合心境与初始资源起跑线。
2. **Close（岁末收盘）**：年终沉淀下来的实际成就感与心力终态。
3. **High（最高阻力突破）**：当年最大机遇窗口（吉星高照或破局时刻的峰值能量）。
4. **Low（最低压力回撤）**：当年遭遇最大挫败、焦虑或健康动荡的波谷耐受线。

### 3.3 趋势标注与关键转折点（Event Annotations）
* **主升浪标签（Golden Cross）**：印绶生身逢财官、三合局汇聚、大运交接换甲。
* **震荡磨砺标签（Support Test）**：七杀攻身、枭神夺食、岁运并临（大运与流年干支相同）。
