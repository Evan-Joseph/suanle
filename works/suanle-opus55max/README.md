## 这是什么

《算了》终极生产版，由仓库 `works/` 下 6 个探索工程审计、取舍后重新融合而成。手机竖屏优先、聊天优先，数据只存在用户自己的设备上。

| 页签 | 做什么 |
| --- | --- |
| **聊聊** | 流式对话、推演笔记折叠条、引用/复制/换个说法/做成卡片；对话中随时弹出摇卦、塔罗、命盘、黄历卡片；会话自动起标题并分类归档 |
| **占一占** | 今日黄历与「今日小确定」；六爻三钱摇卦、塔罗三张牌阵、八字四柱（十神·纳音·大运）、紫微斗数十二宫（三方四正）、年度盘（12 个月起伏曲线） |
| **算了** | 写下烦恼 → 纸张褶皱揉成团 → 物理引擎驱动的抛掷、碰撞纸篓边沿、落入纸篓 → Logo 眯眼一笑：「算了。」 |
| **我** | 小档案（称呼、生辰、它记得的你）、算力账本（生活化类比）、随喜、长明灯、档案库、设置与备份 |

## 融合取舍（摘要）

- **信息架构**：舍弃多路由（切页面会打断对话、重载状态），采用「单页四页签 + 底部抽屉 + 右滑面板」。聊天视图常驻不卸载，流式回复切页不中断。
- **对话协议**：沿用 `<think>` 推演笔记、`<memo>` 画像记忆、` ```suanle ` 互动卡片三段式协议；流式 Markdown 用 `remend` 补齐未闭合标记，标题统一降级，杜绝裸露的 `#`、`*`。
- **Logo 动效**：左三横为左眼、右三横为右眼，永远按「一只眼」整体开合：闲时眨眼、初见会心一眨、倾听时微阖双目、释然时眯眼一笑。修正了旧版六条短横各自抽动的问题。
- **图标**：全部使用绝对线宽（1.6px），「算了」页签图标按 Logo 结构在 24 栅格上重绘，与其它图标视觉重量一致。
- **专业工具**：既是独立面板，也能作为对话卡片；同一份命盘只存一份档案，年度盘按年份存档，不重复、不杂乱。
- **商业化**：入口不重复——每条回复下的「算力 ≈ 半个肉包子」、「我」里的算力账本、每天最多出现一次的温和提醒；深度推演每日 3 次免费，长明灯不限次。

## 技术选型

| 领域 | 方案 | 理由 |
| --- | --- | --- |
| 框架 | Next.js 16 App Router · React 19 · Tailwind CSS 4 | 服务端代理模型、客户端单页体验 |
| 状态与存储 | Zustand + IndexedDB（idb-keyval），localStorage 兜底 | 会话、档案、画像长期留存在本机；支持导出/恢复备份 |
| 动效与手势 | Motion | 弹簧抽屉、下拉关闭阻尼、页面过渡、Logo 眼部动画 |
| 物理 | matter-js（无渲染器模式，驱动 DOM） | 纸团的抛物线、与纸篓边沿的碰撞回弹 |
| 命理 | lunar-javascript（八字/黄历）、iztro（紫微斗数，按需加载） | 排盘精确，交给模型的是算好的盘，模型只负责解读 |
| Markdown | react-markdown + remark-gfm + remend | 流式输出不闪烁、不漏标记 |
| 图标 | lucide-react（absoluteStrokeWidth）+ 自绘「算了」图标 | 线宽统一 |
| 数据库 | PostgreSQL + Drizzle | 只记匿名「算了」计数、随喜订单、算力账本；不存任何对话内容 |

## 快速开始

```bash
npm install
cp .env.example .env      # 填上 LLM_API_KEY；不填也能用，会走本地陪伴逻辑
npx drizzle-kit push      # 建表
npm run dev
```

生产构建：`npm run build && npm run start`。

### 环境变量

| 变量 | 说明 |
| --- | --- |
| `DATABASE_URL` | PostgreSQL 连接串 |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | OpenAI 兼容接口，默认模型 `gemini-4-argon` |
| `LLM_FALLBACK_MODELS` | 主模型不可用时依次尝试 |
| `TIP_WECHAT_URL` / `TIP_ALIPAY_URL` | 收款码内容（生成二维码） |
| `TIP_WECHAT_IMAGE` / `TIP_ALIPAY_IMAGE` | 或直接使用收款码图片 |

用户也可以在「我 → 设置 → 高级」填入自己的模型服务地址与密钥（仅允许公网 https 地址）。
