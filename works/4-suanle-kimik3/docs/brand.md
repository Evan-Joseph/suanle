## 1. 品牌核心内核（Brand Core）

| 维度 | 品牌设定 | 深度阐释 |
| :--- | :--- | :--- |
| **品牌全称** | **算了 · Suanle** | 中文：算了 / 拼音与英文名：Suanle |
| **流派属性** | **动词律动 (Verb Rhythm)** | 具有强烈的动作感、生活化口语感与反差张力 |
| **语义溯源** | **绝妙的东方双关** | “算”字取推演、占算、了解因果规律之意；“算了”则是当代人放下执念、终止精神内耗的最高心法。先算一算，然后算了。自带轻度幽默与松弛感，一秒击中痛点。 |
| **Slogan** | **算一算，然后，算了。** | “算”是探索自我，“算了”是拥抱生活。 |
| **心智画面** | **释然一笑** | 一个人耸耸肩笑了一下，把揉皱的焦虑纸团精准丢进纸篓。 |
| **情绪基调** | **松弛 · 通透 · 反内耗 · 温和幽默** | 拒绝宏大叙事、拒绝中二修仙、拒绝恐吓贩卖焦虑。给予用户一个呼吸与释怀的出口。 |

## 2. 视觉标识（Logo Design & Semiotics）

![算了 Logo](./assets/logo.jpg)

### 2.1 符号学解构（Semiotics）
* **上方图腾：易经【坤卦】（☷ 六断爻 / 地）**
  * 在周易六十四卦中，坤卦纯阴柔顺，象征“地势坤，君子以厚德载物”。乾为进取抗争，坤为承载、包容、适度退让与万物归藏——这正是“算了”在东方哲学里最高级的体现：**不争而善胜，顺应时势，容纳不完美**。
  * 巧妙的是，六道横杠在现代视知觉中，自然构成了一双微眯、放松、充满智慧笑意的**弯弯笑眼**。
* **下方图腾：极简微笑曲线（The Smile Arc）**
  * 一道纯粹而坚定的上扬圆弧，承接上方六断爻，瞬间将古老的易经卦符激活为现代当代年轻人极其熟悉的 **Emoji 微笑脸孔**。
* **色彩系统**：
  * **主色**：纸白 (`#FAF9F6`) 与 曜岩黑 (`#262626`)。
  * **延展辅助色**：低饱和度柔和莫兰迪色系（米灰、陶土棕、雾霾蓝、薄荷淡青），极力避免刺激性荧光色，给用户视网膜与神经系统彻底降温。
