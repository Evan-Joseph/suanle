                              │  【灵境推演】全景信息架构   │
                              └─────────────┬─────────────┘
                                            │
        ┌───────────────────┬───────────────┴───────────────┬───────────────────┐
        ▼                   ▼                               ▼                   ▼
  【1. 太虚灵台】     【2. 天机推演殿】               【3. 宿命酒馆】     【4. 典藏与分享】

                      └─ 灵签筒与掷圣杯

## 2. 五大推演子模块交互与功能详述

### 2.1 模块 A：八字四柱与“人生量化K线”推演舱
* **输入阶段**：
  * 支持公历（阳历）/ 农历（阴历）无缝切换选择器。
  * 精确到出生时辰（支持未知时辰容错）。
  * 触发“真太阳时二十四山罗盘”校准动画（经纬度与时区偏差修正）。
* **输出阶段**：
  * **原局四柱展示**：年柱、月柱、日柱、时柱，天干地支颜色依五行渲染（木绿、火红、土黄、金白、水蓝）。
  * **五行能量多边形雷达图**：展示金木水火土占比分数、喜用神与忌神标识。
  * **人生K线图组件**：
    * 交互式 Canvas / SVG / ECharts / 现代图表渲染。
    * 横轴：1~100岁与对应公历年份；纵轴：0~100人生能量指数。
    * 鼠标悬浮 / 移动端点按弹出气泡：展示该年份 OHLC 四值、吉凶标签（如“32岁 官印相生 主升浪”）、大运流年批语。
    * 支持缩放（Zoom）与拖拽（Pan）时间轴。

### 2.2 模块 B：周易六爻三枚铜钱摇卦台
* **交互流程**：
  * 中央放置青铜卦盅与三枚乾隆通宝。
  * 提供“摇卦”操作：支持点击按钮蓄力抛掷，移动端支持真实陀螺仪晃动手机触发。
  * 铜钱在桌面以 3D 物理翻转掷落，每次掷落实时判断字/背，计算阴阳老少。
  * 屏幕右侧自下而上逐爻生成爻画（阳爻 `—`、阴爻 `--`、老阳动爻带圈、老阴动爻带叉）。
  * 掷满六次后，自动推导出**本卦**、**互卦**与**变卦**，并展开爻辞注解与现代行动指南。

### 2.3 模块 C：塔罗星穹悬浮牌阵
* **交互流程**：
  * 支持三种经典牌阵切换：【单牌指引】、【过去-现在-未来圣三角】、【凯尔特十字深度扫描】。
  * 78 张精美卡牌以 3D 半圆弧悬浮扇面展开，随指针滑过呈现波形回弹。
  * 用户点击任意卡牌，卡牌飞入仪式槽位。
  * 用户点击槽位卡牌，执行 3D 翻牌动效，显化正面/逆位大阿卡纳牌面与神圣批语。

### 2.4 模块 D：赛博灵签筒与掷圣杯
* **交互流程**：
  * 倾斜晃动竹签筒，伴随清脆竹签撞击碰撞声。
  * 随着晃动，一支签脱落而出（展示签诗编号，如“第十九签 上吉”）。
  * 随后掷出两块半月形红木圣杯（筊杯）：
    * 一平一凸为【圣杯】（神明首肯，大吉通过）。
    * 两凸为【哭杯/怒杯】（不允，需重调心念）。
    * 两平为【笑杯】（意向不明，请重新沉思后摇签）。

### 2.5 模块 E：赛博木鱼与正念功德台
* **交互流程**：
  * 屏幕中央放置高精度质感黑檀木鱼。
  * 每次点击，木鱼微震回弹，弹出向上浮动的淡金色文字：`功德 +1`、`焦虑 -1`、`烦恼消散 +1`、`定力 +1`。
  * 伴随空灵清脆的 432Hz 真实木鱼音效。

## 3. 前端有限状态机（Finite State Machine, FSM）

推演核心流程状态转化严格遵循以下流转图：

```
 ┌──────────────┐
 │     IDLE     │ ◄─── 用户进入初始状态
 └──────┬───────┘
        │ [用户选择测算类型并输入生辰/问题]
        ▼
 ┌──────────────┐
 │ CALIBRATING  │ ◄─── 真太阳时罗盘旋转校准 / 呼吸静心
 └──────┬───────┘
        │ [校准结束，进入物理仪式]
        ▼
 ┌──────────────┐
 │ INTERACTING  │ ◄─── 摇动铜钱 / 悬浮抽塔罗 / 晃动签筒 (有意义的交互摩擦)
 └──────┬───────┘
        │ [仪式交互完成]
        ▼
 ┌──────────────┐
 │ COMPUTING    │ ◄─── 3~4.5秒 天机推演动效 (古籍检索、星宿归位、代码流)
 └──────┬───────┘
        │ [推演结束，数据显化]
        ▼
 ┌──────────────┐
 │   REVEALED   │ ◄─── 展示排盘、K线图、五行雷达、大师双轨批语
 └──────┬───────┘
        │ [点击分享]
        ▼
 ┌──────────────┐
 │   SHARING    │ ◄─── 渲染黑金长图海报，提供一键保存图片/复制金句
 └──────────────┘
```

## 4. 离线 Mock 数据与前端完全自洽契约

为保证前端开发同事在无需等待真实后端或外部大模型服务的情况下，能够**直接完成全部视觉交互与逻辑闭环**，必须内置完整且高质量的离线模拟推演引擎（Local Deterministic Oracle Engine）：

1. **生辰干支算法引擎（内置或采用 lunar 算法库）**：根据输入的公历日期直接产出精确干支八字。
2. **K线数据发生器（Seed-based Deterministic Generator）**：根据用户八字哈希值作为伪随机种子，生成波动合理、高低点明确的 1~100 岁 OHLC 连续数据。
3. **大师对话预置策略（Mock Dialogue Trees）**：
   * 针对不同大师角色预置 10+ 轮常见问题（职业、情感、学业、财富）的高质量双轨语料。
   * 支持通过本地配置填入自定义 OpenAI / Gemini / DeepSeek API Key 实现真实大模型流式对话。
